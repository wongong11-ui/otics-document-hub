# Industrial Electrical Training Hub

A free public PDF reader hosted on GitHub Pages. Upload PDFs to `pdfs/` and they are listed automatically using GitHub's public Trees API.

Site: https://wongong11-ui.github.io/otics-document-hub/

See `README-เริ่มต้น.txt` for setup instructions in Thai.

**Public content only:** PDFs added to this public repository are publicly accessible.
